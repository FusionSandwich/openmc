# Blanket family status

Shared periodic topology for physical-normal plasma/blanket/vessel offsets was not implemented in this milestone. The work remained focused on replacing the production global distance solvers and qualifying the periodic plasma and swept-coil kernels.

No blanket speed or correctness result is claimed. Normal-distance construction, reversible parameter maps, nesting, minimum layer separation, and explicit `REJECT_LAYER_INTERSECTION` classification remain required.
