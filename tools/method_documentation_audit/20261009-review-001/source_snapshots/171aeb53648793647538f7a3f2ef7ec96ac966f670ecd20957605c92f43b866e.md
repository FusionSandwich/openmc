# MeshFilter identity and statepoint transform repair

Status: implementation and targeted tests pass in the existing Linux OpenMC
environment; independent Sol acceptance remains pending.

## Change

`MeshFilter` now defines equality using exact filter subclass, mesh ID, and
translation/rotation array values. Its hash uses the same identity fields, so
equal filters necessarily hash equally and tally XML de-duplication retains
filters with distinct transforms. No-transform `None` values compare equal.
Different mesh IDs remain distinct even when their bins coincide.

HDF5 rotation reads accept only a flat native dataset of length 9 or 12. The
first nine stored values are reshaped row-major into the actual matrix; the
optional final three stored angles are not used to recompute it. Translation
is retained. Rotation/translation reject malformed shapes and nonfinite values
at the Python interface boundary.

The C++ convention was traced in `src/tallies/filter_mesh.cpp`: angle input
produces nine inverse-matrix entries followed by the original three angles;
matrix input copies its nine supplied entries unchanged. `to_statepoint`
writes this vector, establishing row-major values first.

loader attempted to load the checkout's Unix shared library and failed with
`WinError 193`. That attempt is retained as NOT_RUN. Continuation-003 identified
the existing WSL `OpenMC-Dev-D` distribution. Explicit `PYTHONPATH` resolved
OpenMC to this checkout, and `openmc.lib` loaded its `libopenmc.so` with SHA256
`f301f7a76a1d4bc1910ea17b582dd31ce70f35cc35690ae5c390c1880ce714a6`. The
designated `/opt/openmc-venv/bin/python` and h5py 3.16.0 were used. Under the
exclusive lease, with one thread, 524288 KiB virtual-memory limit and a
60-second timeout, pytest reported **13 passed in 1.69s**. No environment
changes or software acquisitions were made. `git diff --check` is clean.

Tests cover transform identity, hash consistency for equal values, signed-zero
and integer/float representations, same bins with distinct mesh IDs,
MeshMaterialFilter bin/transform identity, MeshSurfaceFilter class identity,
tallies XML retention, 9/12-entry HDF5 roundtrip preserving matrix and
translation, invalid lengths/shapes, and nonfinite values. After the passing
run, assertions that unequal objects must have unequal hashes were removed
because Python does not require that property. The final test file is therefore
a weaker subset of the passing test version, though it was not rerun after
that assertion-only deletion.
