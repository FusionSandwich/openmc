## Current and preserved call paths

`SurfacePeriodicSpline` constructor reads and verifies the HDF coefficient member, creates `CompiledPeriodicSplineSurface`, detects specialization and prepares conservative physical-span patches/BVH. Specialization is selected once, not by scanning coefficients on each distance query. The current adapter reconstructs inexpensive root options and compares its solver string per distance call; this cannot be assumed to explain34.82seconds without attribution.

With manifest solver=`layered`, each query enters compiled `distance()`: exact circular torus, shaped axisymmetric, or generic periodic branch. Real WISTELL has varying axis/radius and uses the generic branch. `distance_reference()` is an explicit separate choice; generic `distance()` does not call the private interval precursor. Optional sparse oracle verification is compile-time guarded. Current CMake flags have performance counters OFF and oracle verification OFF, so their absent measurements cannot be interpreted as zero counts. Compilation metadata specifies Release `-O3 -DNDEBUG`, strict floating point (`-ffp-contract=off -fno-builtin`); old archive compiler flags are unknown. The effect of those flags has not been measured.

Generic per-query work is direction normalization, conservative root box intersection, ray basis and scale-aware tolerances, then front-to-back fixed-stack BVH traversal. Leaf work checks patch boxes, intersects two proxy triangles for parameter seeds or computes segment-to-triangle distance against the proxy error tube, and runs patch-local projected2x2 Newton. Newton evaluates local power polynomials plus trigonometric position/derivatives. Low incidence (<0.25) marks subdivision; incidence<1e-4 rejects the ordinary Newton root. Difficult patches use scalar implicit evaluate/directional derivative, sign brackets and stationary tangent search; remaining flagged crossing intervals try a3x3 parameter seed grid. There are no global reference calls in this generic body. Evaluate/classification computes local cylindrical/poloidal coordinates and axis/radius spline samples; normal adds their derivatives and normalization. Scattering in solid Fe56 causes repeated boundary queries from collision sites; boundary crossing also requires sense/evaluate/normal. Calls and crossings per history were not measured.

The512x192 radius coefficients and4periods imply512x768=393216 physical-span patches under the current construction. This is not a new count measured at runtime. Runtime load/BVH build is nested in initialization (8.908987740s). The old/current coefficient file bytes match, so simply substituting an old HDF file will not reduce that patch count.

`SOURCE_BANK_MANIFEST_009.json` records the compared files and function extraction. The generic solver, patch builder, patch evaluator, shaped solver and exact solver extracted from preserved HEAD3041a938 and current working source are identical after all whitespace is removed. This is textual evidence rather than a formal semantic proof. Constructor validation and exact-specialization detection differ; the current exact-equality gate must stay. The preserved old adapter caches options/solver and uses a native exact-torus helper only for exact circles. That helper does not accelerate nonaxisymmetric WISTELL. Its old `.found ? distance : INFTY` conversion must not be restored: the current checked adapter throws for terminal unresolved/invalid hit results.

## Nearest-root and classification obligations

Current root option defaults are absolute t1e-11cm, relative t1e-11, absolute f1e-10cm, derivative1e-12, duplicate multiplier8 and tangent residual multiplier16; the adapter chooses96initial subdivisions and7levels with stability enabled. Those initial/refinement values govern reference/interval solver paths; they are not a96-way per-ray global loop in the generic patch body. Generic coincidence push is max(64*absolute_t,8*absolute_f,64*epsilon*characteristic_length); projected residual tolerance is max(absolute_f,64*epsilon*characteristic_length). Native torus and exact compiled paths have different policies. Do not relax these to meet the cost gate.

The `enable_bernstein_prefix` root option documents an exact-control COIL accelerator; it is not a generic periodic plasma prefix certificate. For a claimed first root at t, every earlier possible patch/ray interval must be conservatively excluded or fully resolved; a converged candidate alone cannot certify the prefix. Rootless results need complete exclusion, not failed Newton seeds. Seams require canonical parameter ownership and deterministic duplicate handling; tangencies need stationary-root detection even without material transition; coincident pushes need a justified excluded interval and consistent native sense/normal behavior. The generic function currently accumulates diagnostics and may fail local seeds without a terminal unresolved marker, while its `certified_excluded_intervals` counter subtracts candidate count from total patches. That counter's name is not an independent interval proof. This is an acceptance obligation to audit, not evidence that the pilot lost particles. Pilot native diagnostics were empty; real-WISTELL independent first-root oracle remains NOT_RUN.

## Concrete isolated next proposal: trace before optimization

Prepare a renamed standalone generic adapter/kernel against the existing pinned library, with unchanged evaluate/normal/root policies. Enable existing thread-local counters in only the isolated kernel copy and add a bounded journal at distance entry/exit: origin,direction,coincident,solver path,disposition,distance,residual, candidate nodes/patches, proxy seeds, Newton iterations/failures, tangent/stationary/subdivision counts and exact earlier-interval rejection reason. Capture the first4096 complete query packets plus every unresolved/failure up to a stated byte ceiling; count all queries per history separately. Use independent counters for scalar evaluate, normal and any global reference call. Instrumentation timing is attribution only and cannot be the accepted speed measurement.

A future separately authorized single block should first validate the preserved failing sense packet using the diagnostic probe, then run the current frozen bank/workload through unchanged native and instrumented isolated paths. The sampled bank must preserve incidence, boundary/coincident status and multiple roots. Replay the same bank against preserved source in an isolated renamed class only after binding it to the same geometry/options and establishing nearest-root/classification compatibility with an independent oracle. Stop on mismatch/unresolved/resource failure; retain complete finite receipts; no automatic successors. Do not compile a new production library, alter full target geometry, turn tallies off for acceptance, relax root tolerances or reuse historical timings as matched controls.

Only after counters identify the dominant cost should an algorithm patch be proposed. Candidates include front-to-back BVH layout/leaf ordering, tighter conservative exclusion bounds or fewer safely bounded seed operations. Each must maintain earlier-interval exclusion and all accepted complete-query outcomes. Caching adapter options is a small independent untested proposal, not the load-bearing plan for a159.72ratio. This audit launches none of these experiments.
