misses a positive ~8.33e-17 cm contact; a08 misses a tangent at 2 cm; a15 differs

## Source gates for the new exact plasma dispatch

Historical composite SurfacePeriodicSpline directly calls shared native
torus_distance only when the compiled representation reports exact circular
torus and the reference solver is not requested. The current implementation
already detects exact constant coefficients using exact equality, and its
test_near_constant_is_not_exact exercises one-ULP perturbations. Preserve that
gate: no averaging or tolerance-based promotion of near-constant/nonaxisymmetric
geometry to a torus. Preserve content identity, z offset, radii/units, nonunit
direction contract and coincident semantics; prove evaluate/normal/distance
refer to the same admitted torus. Check reference-mode behavior separately.

**Do not transfer the historical adapter wholesale.** Its generic branch returns
`result.found ? result.distance : INFTY`, whereas the current adapter calls
checked_stellarcsg_distance, which throws on terminal unresolved and invalid
negative/nonfinite hits. Keep the checked adapter on every generic path; an
uncertain interval must never become an authoritative miss. Direct analytic
native dispatch has its own native-root/normal/boundary negative controls.

Required decisive source/test cases: exact torus enter/inside exit, tangent,
seam/equator, coincident direction, normal and cell/material token; exact vs
reference options; one-ULP changes to each admitted coefficient family; nearly
constant but distinct coefficients; invalid radii/dimensions/data/member identity;
unresolved generic result; negative/nonfinite generic hit. Do not interpret
portable checks or old rate parity as new transport/tally qualification.

output and result validation are available. Record actual external monotonic
