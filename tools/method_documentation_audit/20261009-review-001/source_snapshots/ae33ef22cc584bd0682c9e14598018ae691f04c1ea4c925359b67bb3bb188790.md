The available working-tree delta now includes _bins_key in both equality and
hash, plus MeshMaterialFilter.__hash__ delegating to the base. This addresses
the root's source-supported counterexample in which two valid material-bin
lists on the same mesh/transforms compared equal but hashed differently.
_bins_key flattens bins through dtype=object, preserving values/order. Valid
MeshMaterialFilter bins are an integer (element,material-id) array, so distinct
material/bin entries now participate in both operations. Empty/no-transform
MeshMaterialFilter instances lack _rotation; getattr(None) in the new identity
avoids that missing private field. These statements are source tracing, not
executed fixture results.

_transform_key now forms tuples of numeric array entries rather than byte or
string representations. Python numeric equality/hash rules make signed zero
and equal int/float values consistent. Public setters reject nonfinite values.
Exact subclass identity separates MeshFilter, MeshBornFilter, MeshSurfaceFilter
and MeshMaterialFilter. MeshBornFilter inherits the base unchanged;
MeshSurfaceFilter derives mesh bins including surface labels, which must be
retained in identity. Matrix-shaped versus 3-angle representation has different
tuple length, avoiding accidental equality. Equivalent rotations encoded
differently need not deduplicate; they must not collapse distinct transforms.

Relevant consumer: Tallies._create_filter_subelements uses a dictionary keyed by
filter, emits the first equal filter and may mutate a later filter's ID to the
retained ID. Equality and hash must therefore agree, and all semantically
distinct bins/transforms must survive export. Tally set operations and filter
lookup also consume this identity. Mutable bins/transforms/mesh IDs should not
change while a filter is held in a dict/set; that is an existing mutable-object
design limitation, not a newly validated immutability guarantee.

HDF5 base rotation handling matches native src/tallies/filter_mesh.cpp: native
stores nine row-major inverse-matrix entries, optionally followed by three
original angles. The proposed Python path checks a flat finite length 9/12
payload and preserves the first nine matrix values rather than recomputing
angles. MeshSurfaceFilter and MeshBornFilter inherit this base reader; valid
consumer tests must establish their type dispatch and equality/hash behavior.
MeshMaterialFilter owns its reader, bin identity and translation serialization;
the base matrix reader does not qualify a material-filter rotation interface.
