Source explains the budget: repeated `minimum()` calls inside sign/bracket

then refines proposals through further all-span Newton work. Projection repeats
global separation checks and creates per-span stacks. `evaluate()` repeats a

then request another normal. The separate native probe actually records 18
evaluations, 28 normals and two boundary validations. At those two boundary
queries, validation plus directional sense duplicates normal service. This
obligation was preserved, not deleted or cached by this patch.

call counts. C++ `new` counts exclude malloc/realloc/aligned allocation and
are a lower bound. `nextafter` counts include geometry construction; its cycle
fraction was not separately measured. No profiler overhead subtraction is made.

## One isolated optimization

`candidate-04/optimization.patch` changes only
`dev/stellarcsg/src/certified_spline_offset.cpp`. It adds three immutable scaled
interval vectors per span, computed with the existing `sample` and `scaled`
expressions at `[0,1]` for derivatives 0, 1, 2. `center()` returns that stored
value only for exactly the same interval/derivative; other queries execute the
original expression. Constructor and query round-to-nearest checks remain.
The constructor's regularity test still calls `sample()` directly. The cache is
populated before publishing each span, and neither spans nor metric scale is
mutated after construction.

This is value reuse, with the same outward arithmetic and enclosure endpoints.
It changes no domain pruning, root ordering, budget, classification, normal
admission, fallback or tolerance. It needs no geometry-specific ownership
certificate. Extra permanent storage is 288 bytes/span on this platform:
18 KiB for 64 spans, at most 1.125 MiB for the admitted 4,096-span maximum.
It does not reduce allocations. Geometry-construction overhead is additional;
no comparative construction-time acceptance was attempted.

Paired diagnostic profiles retain all search counts/dispositions and reduce
outward-rounding calls by **22.97%**. Summed exclusive offset-service time improves
1.677x; this instrumented observation is supporting cost evidence only.
Projection falls from 479.76 to 116.01 ms, minima from 1,597.38 to 962.25 ms.
Proposal time varies upward and is not claimed to improve.
