## Supported domain and changes

The compile option and runtime option remain OFF by default. Opt-in supports
one untransformed root universe of void CSG cells, built-in finite axis planes,
exact unit-axis rays, cell-flux tracklength and representative surface-current
tallies, and no finite time cutoff or other transport features.

Vacuum admission is deliberately narrower: exactly six distinct vacuum planes,
two per axis, form a common outer box. Every cell must conservatively imply
all six signed enclosure halfspaces from its Boolean expression, without
using BoundingBox's finite infinity alias as proof. Every conservative cell box must
be nondegenerate and contained in it; their union extent must reach all six
faces. Internal or masked vacuum placement fails model validation before any
movement/scoring. Transmission contacts can still be masked and skipped.
The Boolean boxes are conservative sufficient conditions, so this rejects some
otherwise meaningful models. It does not assert a general boundary-relevance
algorithm or prove global coverage of arbitrary Boolean partitions.

Every positive exact local difference must round to a finite double strictly
below `INFTY` (DBL_MAX). An interval rounding to that finite sentinel is rejected
before movement/scoring, preserving the native disabled-cutoff convention.
No physics-kernel tolerance, geometry payload, or native cutoff logic changes.

The deterministic client snapshots and restores all injected plane/material
mutations, verifies restoration after each query, reuses one Particle across
healthy and failing sources, checks context reset and epoch progression, and
executes two initialize/finalize cycles. Overflow injection preserves a valid
enclosure, so both injected rows actually reach the arithmetic guard. A healthy
row follows faults to test recovery. The original faulty harness remains in
the independent snapshot commit and in the other checkout.

The Fraction oracle derives terminal vacuum from leaving the explicit outer
Boolean enclosure, rather than from any BC in a contact group. Acceptance
compares every ordered event and per-bin score and rejects deleted gaps,
wrong ownership, flux redistribution preserving totals, wrong current, and
missing contacts. Full legacy itineraries are compared between a runtime-off
experimental build and a compile-option-off build with matching headers.
Legacy gap witnesses are retained separately from supported exact-path rows.

## Reproduce

Run `dev/stellarcsg/tests/axis_review_acceptance.py` using installed Debian WSL
Python. It requires the fresh recorded host inventory, existing compiler,
CMake/HDF5/libpng/vendor sources and unchanged retained-library hashes. The
native parser also requires a nonempty cross-section catalog; fixtures name
the already installed ENDF/B-VII.1 index explicitly and pin its hash. All cells
remain void and no nuclide data is loaded or downloaded. It
acquires the existing shared local compute lease atomically and never reclaims
another owner's lease. It creates new source/build directories in `/var/tmp` and
an explicitly named artifact directory here, with no overwrite or dependency acquisition.
It allows one CPU and build worker, 1.5 GiB virtual memory per build/configure
child and 1 GiB per test child, 900 seconds by default, 150 seconds per configure,
and 300 MiB combined native/output data. `--phase-seconds 1800` admits the full
fresh ON/OFF integration check: the prior acceptance took 1322.576 seconds
including its retained timeout and explicit continuation. The full repository's
retained experiment reports are excluded from the isolated native source copy.
The first failure stops the phase; no retry or successor runs automatically.

The isolated WSL source has no Windows `.git` pointer. Explicit archival metadata
labels it `v0.0.0-axis-review`, records the upstream base commit, and identifies
the source manifest as the modified snapshot identity. The retained failure
found HDF5 already, so this is a path/configuration diagnosis rather than a
claim that dependencies were missing. Loader path, binary hashes, source/input
hashes, and compile-definition consistency are acceptance requirements.

The initial native build succeeded, but initialization stopped for the absent
cross-section catalog. The next explicit corrected phase rejected reuse after
its missing-file check: this WSL mounts `/tmp` as tmpfs and idle shutdown removed
the earlier outputs. Both failure receipts are preserved. Builds now use
persistent `/var/tmp` storage and new directory names. No failed row is counted
as native acceptance.

This scaffold repeatedly scans/allocates/sorts. Passing finite deterministic
rows would establish only this restricted correctness slice, not production
speed, non-faceted coil fidelity, general plasma certification, or physical
per-coil ownership. Installation/ABI distribution remains outside scope.
