### Confirmed invariants and cost hypotheses

- Source inspection: exact-control representation uses the same constant-metric
  offset-union definition for minimum classification, ray distance and physical
  gradient normal. Circular offsets allow arbitrary regular centerlines;
  unequal radii require xy-planarity, constant radii and axial frame conditions.
  This does not admit varying-frame rectangular solids or collections.
- Source inspection: `minimum` initially visits all spans, prunes only with
  strict conservative hull-distance bounds, searches stationary minimizers
  of the exact periodic C2 curve, and retains an enclosure/budget outcome.
  A minimum enclosure whose sign is decisive can classify even if the
  convergence precision is incomplete; a straddling boundary cannot.
- Source inspection: accelerator proposals at 128 ray positions are hints.
  Acceptance retains global signed endpoint bounds, unique projection and
  strict derivative over the local bracket, complete earlier prefix exclusion,
  root-distance/residual bounds. Proposal failure returns to ordered fallback.
  Outside prefix uses every potentially relevant span's tensor Bernstein
  bounds; inside prefix uses a fixed exact center witness to bound an entire
  slab. The latter is sufficient to prove inside but can be conservative.
  Neither endpoint signs nor sample points alone are a miss certificate.
- Source inspection: fallback pushes right then left on its stack, so processes
  eligible domains in increasing ray order. Its same-sign pruning requires
  whole-domain derivative/projection bounds; depth/precision/budget failure is
  unresolved. Exact support lists retain even contacts and strictly positive
  dyadic contacts for noncoincident queries; an exact unsuppressed t=0 is
  explicitly unresolved rather than silently removed.
- Cost hypothesis: `evaluate` performs `minimum`, calls `normal` in its narrow
  certified boundary band, then returns zero. `Surface::sense` sees zero and
  calls `normal` again. Each normal independently repeats minimum/projection.
  Reuse could remove two repeated services **only if the already-proved result
  is available for the same requested state and still meets the normal bound**.
  Dropping evaluate's validity check changes fail-closed behavior. Frequency
  and dominant cost fraction are NOT_MEASURED here; source counting is not
  native profiling. Mutable shared Surface cache risks OpenMP races.
- Source inspection: actual `CellFilter` traverses coordinate-level cell IDs.
  Chart/member IDs cannot substitute. Native mesh processing consumes actual
  transport segments; `StructuredMesh` still has its short-flight branch
  `total_distance < 2*TINY_BIT`. An exact synthetic redistributed-bin witness
  is supplied, but this milestone does not execute that native branch.

## Compatible composition architecture

Compile one immutable represented solid G with a canonical identity containing
exact coefficients, member/selector, container and payload hashes, metric and
frame, units, seam convention, arithmetic contract, compiler version and
derived-bound proof identity. Distinct fidelity types represent approximations.

1. Use conservative immutable span BVH boxes (control hull inflated by the
   admitted metric section) and outward/exact slab predicates. Reject only
   certifiably empty **whole domains**. Inner/outer sandwiches may certify
   membership when separated; their ambiguous band goes to the same G solver.
2. Generate fast floating candidates without changing G. Validate every
   candidate with complete local roots, trims, multiplicity/contact semantics,
   and complete earlier-domain coverage. First hit sorts by ray distance.
   Budget failure returns unresolved, never a sampled authoritative miss.
3. For an exact planar-normal direction, metric w dot c'(u)==0 on every relevant
   span, stationarity H(u)=(o-c(u)) dot c'(u)=0 is independent of ray parameter.
   Isolate all H roots, include chart seams and finite-domain endpoint duties,
   then solve both branches of Q(u,t)=1, a quadratic in t. If H vanishes
   identically, preserve a continuum case. Validate global ownership and
   order roots by t, not u. The new executable implements only the straight
   interior-fiber specialization; full cubic H isolation/binding is NOT_RUN.
4. After a validated boundary event, remove a redundant owner search only
   under a complete independently checked global certificate bound to this G.
   Recheck bound/member/frame/metric/arithmetic identity and all ordered pairs.
   Retain arbitrary-origin classification, earlier roots and event semantics.
5. Share query results through a per-particle immutable result token containing
   state, normal enclosure, membership, incident surfaces, cell/material/image
   and root/prefix certificates. Geometry state advancement, collision, changed
   direction, cell/image transform, reload, arithmetic/tolerance changes, or
   invalid normal/proof invalidate it. Position rounding after advancement
   requires a separate validated relation; a same-ray heuristic is insufficient.
   A cache hint may select traversal order without certifying skipped domains.
6. Native tally API scores accepted segments/events with actual persistent
   cell/material IDs. Compare local bin arrays and energy bins, not just sums.
   Crease normals remain multivalued unless the physical boundary operation
   chooses an admitted normal law; tangent events need one-sided membership.
