## Why the coil is slow: measured versus hypothesized

The profile's native transport observation used 200 histories and the existing radius-5 cm round coil. Exclusive coil-service cost was:

| Service | Share | Important observation |
|---|---:|---|
| Certified nearest-point minimum | 67.19% | 12,999 calls; repeated all-span searches |
| Projection proof | 20.18% | 965 calls; about 68 counted C++ allocations per call |
| Newton candidate proposals | 10.09% | 8,121,984 span visits |
| Other prefix/dispatch work | about 2.55% | Conservative ray coverage remains necessary |

Native distance median was 2.558 ms and p99 4.777 ms. No normal calls or boundary-band validations occurred in this transport profile. Thus the earlier source observation of duplicated normal work is real, but is not the dominant measured cost in this fixture. A separate boundary probe did exercise it.

The cache stores geometry-only interval values for exactly the full parameter interval and derivative orders 0–2. It preserves the original arithmetic expression, root ordering, budgets, fallbacks and normal admission. Three interleaved uninstrumented complete primitive observations show 1.993× throughput versus the same offset implementation, with 18 KiB extra immutable storage for 64 spans. The optimization is proposed, not applied to production.

The candidate's complete primitive throughput is 0.01761% of the exact circular native torus control. The primitive test includes distance, normal, directional sense, coincident exit and a miss. It is not the historical transport workload (0.1299%). Reaching 80% on this primitive workload would require approximately 4,543× further improvement. This is evidence that the current runtime algorithm needs a structural change; it is not a proof that a faster general method is mathematically impossible.

## Accuracy and geometry limits

- The cache preserves all non-timing fields in the 160-query bank in both modes, including 69 first hits and 91 misses, and retains the historical certificate criterion. Root checked the patch/source hashes and the comparison receipts; the independent reviewer must challenge the proof and runtime bindings.
- Instrumented baseline/candidate transport has identical checked local tally metadata and arrays over 20 cumulative statepoints. This supports regression safety only. Sparse bins and shared implementation paths do not establish physical accuracy or all tally capabilities.
- Nine blocked normal queries remain. The independent audit identifies these as no-hit origin telemetry: one lacks unique projection and eight exhaust the minimum budget. They are not nine failed returned-boundary distances. Arbitrary-point normal service is still incomplete; boundary/reflection failures need their own tests.
- The general coincidence policy suppresses a finite positive interval. Closely separated distinct boundaries require clearance/ownership handling. General tangencies, seams, tiny tracks and nonlocal overlap remain acceptance concerns.
- The current coil and ZTorus have matching nominal 5 cm circular sections. The spline axis differs from an exact circle by a retained bound below 0.243 micrometres. This is a geometric proxy, not exact solid identity.
- The old equal-volume flat ring has radial halfwidth 5 cm and axial halfheight 5π/4 cm. It is a different rectangle. The new common annulus uses radial/axial halfwidths 5 cm, giving a 10×10 cm rectangle in both mathematical references.
- The current elliptical swept schema cannot represent a rectangle by changing radii. A synthetic 30×30 cm annulus is not physical WISTELL winding-pack qualification. Correct filament data alone does not bind section frames, corners, trims and CAD correspondence.

## Ordered next steps

### 1. Finish the low-cost correctness gates now

Luna is continuing the existing tally task in explicit WSL distribution `OpenMC-Dev-D`, using already-local dependencies and checking the imported checkout. Add decisive signed-zero and integer/float hash controls. Root also found that inherited `MeshFilter.__eq__` can ignore `MeshMaterialFilter` material bins while that subclass's hash includes them; actual valid fixtures must test and preserve this identity. Check other subclasses and the Tallies XML deduplication consumer. No Windows/Linux loader workaround may turn an uncollected test into PASS.

The cross-section owner is continuing one bounded checker/reference-export block with fresh outputs. The hybrid owner may execute its rational contract checker once. The shared lease serializes compute; occupied means defer, never poll or reclaim automatically. These checkers qualify their finite fixtures/contracts only.

### 2. Independently accept the cache patch, then measure real transport

The hybrid Sol chat has been assigned the exact cache patch and evidence. It must review arithmetic equivalence, initialization, rounding guards, immutable geometry/scale, exception behavior, storage limits, thread safety and cross-DSO binding. Accepting source safety does not accept physical fidelity or the 80% target.

After acceptance, root can integrate only the exact cache patch and run a fresh bounded uninstrumented native transport A/B, with matching source/data/material/seed/thread/tally roles, sufficiently long native denominator, tally-off/on controls and raw local-bin comparison. Preserve the historical libraries and outputs. Refresh the full operator inventory before building and use the shared lease.

### 3. Make the rectangular method actually usable through OpenMC

The cross-section chat is specifying a minimal native route based on separate smooth face Surfaces composed by OpenMC Regions. This allows native directional sense to act per constraint at corners. A whole-solid canonical face normal is insufficient when a ray simultaneously enters one face constraint and exits another.

Start with the exact circular-annulus rectangle fixture to test native cell/material/tally behavior. Then admit a clearly defined cubic swept rectangular solid with complete side roots, trims, endcaps, seams and incident faces. Finally bind physical WISTELL geometry. Passing the annulus specialization cannot establish general curved-coil performance.

### 4. Redesign expensive runtime proof work using measured costs

Prioritize one compatible pipeline for the same admitted solid:

1. Precompute immutable span bounds and geometry-only enclosures; use a conservative hierarchy to reduce minimum/projection span visits.
2. Use inexpensive floating candidates or membership filters, with outward bounds and exact/certified fallback in ambiguous cases.
3. Validate complete earlier ray coverage and all applicable contacts; never promote samples or a later valid root to a first-hit certificate.
4. Remove redundant nonlocal ownership checks only with a complete independently checked offline certificate bound to the loaded container/member/frame/metric/arithmetic.
5. Reuse certified results only through explicit valid state tokens. Shared mutable Surface caches risk races; moving/rounding position, changed direction or transforms can invalidate a result.
6. Add algebraic specializations for exactly admitted planar-normal directions where stationarity becomes independent of ray distance. Retain full stationary-root, seam, continuum and branch completeness; near-zero is not exact-zero.

A BVH may reduce span work but cannot by itself be assumed to close a roughly 4,500× primitive gap. The acceptance experiment should count avoided minimum/projection calls and fallback tails, then measure complete native work. Keep a generic exact path, a documented fast path and an unresolved outcome. Do not silently switch to a different represented solid or relax tolerances.
