# gate-01: represented-P00 transport ratio after patches v2+v3 — pre-registration

Written October 8, 2026, before the run. This measures the project speed metric for the
**derived, represented P00 facet model** against the fixed 30x30 cm flat rings. It is not
physical-winding-pack acceptance: continuous CAD/section/frame fidelity, physical-coil
ownership, native event semantics and independent review all remain open.

## Configuration

* One runtime for both models (as in the retained speed block): `nextup3`
  (`libopenmc.so` `ceb7bd88...`, patches v2+v3; bitwise identical to the unpatched control
  in ab-02/ab-03 and xval-01/02).
* Inputs: retained 100k worker XML (100 batches x 1,000; production tallies 1-3; Fe56 nominal).
  Seeds 1741 and 1742 use the retained files unchanged; seed 1743 changes only the `<seed>`
  value of the seed-1741 settings.xml.
* 3 seeds x 2 models x 5 repeats = 30 runs in 5 randomized complete blocks (order seed
  20261012); one thread, highest CPU, 1 GiB, quiet admission and telemetry as ab-02;
  private lock; shared campaign lease untouched; stop at first failure; no retry.

## Gates

* Validity: exit 0, 100 complete batches, no tracking diagnostics, finite tallies; seeds
  1741/1742 bitwise equal to the retained statepoints of the same seed and model; within every
  (seed, model) arm all repeats bitwise identical; arm CV <= 5%.
* Per seed: R = median T(P00) / median T(ring). PASS_ROBUST if R <= 1.25 and
  max T(P00) / min T(ring) <= 1.25; PASS_MEDIAN if only R <= 1.25; FAIL if R > 1.25.
* Overall: PASS if every seed is PASS_ROBUST or PASS_MEDIAN; report also the pooled ratio
  (sum of per-seed medians) and initialization, transport, statepoint and process-wall times.
  Cold geometry construction (payload load + BVH/precompute) is inside initialization and is
  not separately timed: UNKNOWN as a separate phase.
