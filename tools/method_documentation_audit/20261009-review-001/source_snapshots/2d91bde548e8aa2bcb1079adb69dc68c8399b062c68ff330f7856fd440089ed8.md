# Historical CSG methods: strongest results and current recommendation

## Finding

The user's concern is supported by the saved records: earlier CSG implementations achieved substantially stronger performance than the new certified offset path. The new path is not our best demonstrated performance implementation. It supplies a restricted correctness mechanism and reference, with a large runtime cost.

The strongest native-speed results belong to exact analytic specializations. The strongest real-coil set performance result belongs to the older local span solver plus shared coil BVH. Those are distinct achievements with distinct correctness limits.

## Why we cannot simply approve the old generic solver

Later strict replay of the recovered-old kernel found four discrepant cases: a03, a06, a08 and a15. The a03 case returns a later root at about **0.502 cm** instead of the first root at about **0.002 cm**. This is a decisive first-crossing error, even though a finite test corpus and geometry-debug previously passed. Tangency/boundary cases and stationary-point completeness also remain concerns.

`stellarcsg-local-continuation-20260925/dev/stellarcsg/reports/local-cont-20260925/strict-old-01/oracle-comparison.json` preserves all four comparisons. The raw candidate summary reports only one internal failure, while the independent comparison finds four discrepancies; internal success counts are insufficient.

The recovery stream repaired the capsule-inside earlier-entry defect, but did not prove complete earlier-root exclusion. Its review documents tangent failures, fixed sign-scan gaps, floating box pruning and unproved classification. The specific exact analytic torus fast paths are separate from these generic solver failures.

The new certified path pays for conservative global minimum, projection and ray-prefix proof repeatedly. It represents a restricted constant-metric offset; it is not a drop-in faster version of the legacy varying-frame swept definition. Its improved correctness obligations do not imply that its runtime architecture is suitable for production.

## Recommended direction

1. **Reuse the demonstrated exact analytic dispatch.** Preserve exact torus/circular-coil paths and ordinary cylinders/planes for exact annular rectangles. Inspect source provenance before transferring: the composite adapter has cached direct `torus_distance` branches that the inspected Astra adapters do not currently contain. Do not label a cubic near-circle as an exact circle; an approximation requires its own explicit fidelity contract.
2. **Use the old shared BVH/local solver as the performance architecture to repair.** Recover its conservative span/set traversal, local candidate work and low-allocation native adapter. Its successful performance is stronger evidence than continuing blind global searches.
3. **Use the new restricted certificates as a verifier and fallback.** Add a complete first-root/local-domain admission mechanism around cheap candidates, with precomputed geometry proofs where possible. Track fallback frequency and tails. This is a proposed composition; the old rounded-frame solid and new constant-metric offset must be reconciled before one certifies the other.
4. **Compare all candidates on the same benchmark.** Declare solid, frames, section, tolerances, source, materials, binary, completed queries, native adapter semantics and tally state. Include thin chords, first-root traps, tangencies, seam/corner cases, normals, inside origins and local bins. Use sufficient native duration and preserve unresolved/failure outcomes. Report exact-specialized, generic curved and physical rectangular results separately.
5. **Keep the physical rectangular gate explicit.** The fastest 48-coil study used standardized circular 1 cm tubes. No record here establishes a general accurate 30×30 cm WISTELL winding-pack method at 80% native throughput with full tally closure.

The performance target has already been met for exact analytic specializations. The unresolved problem is retaining the older fast local architecture while supplying trustworthy generic geometry and first-crossing semantics. The current costly certified method should not be presented as the best-performing production direction.
