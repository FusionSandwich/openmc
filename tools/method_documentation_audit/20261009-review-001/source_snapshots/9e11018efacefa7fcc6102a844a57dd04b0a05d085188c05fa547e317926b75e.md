# Frozen native Stage 1 scope and execution plan

Status: implementation authorized, acceptance pending. Foundation checkpoint
P00_DYADIC_AXIS_CHECKPOINT_20261001.md is an experimental dependency, not native
proof. This plan precedes implementation and execution.

## Supported functional unit

An OFF-by-default compile option and an explicit runtime opt-in enable one
universe/coordinate level, material-void CSG cells, finite built-in x/y/z planes,
unit-axis rays and transmission/vacuum boundaries. All geometry is checked;
nonplanar enclosures, transforms, lattices, material transport, coplanar parallel
rays, finite time cutoffs, derivatives, mesh/time/spatial filters and other
scoring/variance-reduction features are unsupported. Unsupported is terminal;
there is no silent legacy fallback after opt-in.

The particle owns an anchored ray epoch, exact current/event coordinate keys,
complete deduplicated contact group, strict incoming/outgoing side state,
pending successor and consumed origin coordinate. Query all native root cells
using their existing Boolean Region evaluator with certified side values.
Order contacts with the accepted dyadic primitive. Masked contacts are evaluated
without rounded virtual motion. True ties change owner atomically. Choose the
legacy representative by minimum native user surface ID; score one native
current for that representative. This explicitly does not count every member
of a contact group as a separate current.

Every positive owner interval is scored using the rounded exact difference of
its endpoint coordinates, never subtraction of rounded absolute times. Set
the endpoint coordinate to the certified plane offset before native scoring.
Consume all exact origin contacts in the epoch; a positive future contact is
never suppressed by FP_COINCIDENT, FP_PRECISION or TINY_BIT. Reject overflow or
invalid/stale context before movement. Reset context on source/geometry reset;
reject direction/frame changes. Default dispatch and frozen libraries stay
unchanged. New experimental clients must use the exported compile definition
and matching new library, to avoid GeometryState ABI mismatch.
