## Inspected architecture and conservative replacement

Current `compiled_swept_surface.cpp` retains the older span BVH: power-range
boxes, four-span median-split leaves, point-box lower bounds and near-first
traversal. `compiled_swept_surface_set.cpp` retains the shared coil tree with
two-coil leaves. The historical composite checkout has the same architectural
pattern. The old boxes apply to its rounded-frame representation; they are not
used as certificates for the new cardinal-offset solid. The independently
recorded old wrong-root failures a03/a06/a08/a15 remain disqualifying for restoring
that old generic return path (a03 about 0.502 instead of 0.002 cm).

The proposed tree instead encloses every **original transformed four-control
hull** already used in `CertifiedSplineOffset::minimum`. Parent boxes take the
union of those hull endpoints and an extra outward nextafter. A centroid is used
only to partition indices. It never enters a pruning predicate. Four-span leaves,
median recursion, maximum 4096 admitted spans, immutable construction and a
checked fixed 64-entry traversal stack follow the old architecture.

For a query interval p and a valid finite squared-distance upper bound U, a node
is omitted only when the existing interval `length2(p-node.hull).lo > U` proves
strict separation. Equal/touching/uncertain bounds retain the node. An eligibility
mask returns to the original span order, so hierarchy order never orders roots.

- Minimum keeps witness(0,0), every surviving original hull check, stationary
  interval-Newton contraction, endpoints/witnesses, queue lower bounds, depth
  and node budgets, and complete/unresolved semantics. A node excluded against
  the initial witness upper bound remains excluded against any later smaller
  upper bound. No sampled nearest point admits a result.
- Projection keeps all local joined-chart convexity/stationary/normal proofs.
  Only its global remote-span/tail loop consults the same tree, using the existing
  nearest upper enclosure. Whole-span separation certifies all omitted tails;
  retaining a node leaves the original per-chart subdivision proof untouched.
- Ray root search, first-prefix certificates, even contacts, coincidence, scale,
  frame admission, FE_TONEAREST guards, normal/classification validation and all
  public API remain unchanged. No arbitrary-point classification is deleted
  from a reach assertion, and no approximate axis becomes a torus dispatch.

The exact mathematical intent is conservative hull exclusion on the same admitted
offset. This text is the implementer's rationale, not independent acceptance.
Tree construction arithmetic, masked-domain coverage, interval point boxes,
stack/index limits and all exceptions need separate review. Projection's actual
visit count can decrease because a whole domain has been proved separated; its
existing visit ceiling is unchanged. A prior budget exhaustion must never be
silently recorded as a miss. Any newly resolved query needs a complete certificate,
not an assumption that matching a finite bank proves general behavior.
