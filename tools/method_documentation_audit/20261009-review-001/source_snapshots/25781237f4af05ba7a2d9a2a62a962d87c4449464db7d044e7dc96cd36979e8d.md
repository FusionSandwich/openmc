# Custom coil/plasma methods versus built-in CSG: elapsed times

## Accepted comparison scope

The user explicitly allows built-in controls that approximate the target shape less accurately. Built-in torus, cylinder/plane rings and simplified coil collections are legitimate cost references. The main target is built-in CSG elapsed time; DAGMC comparisons remain secondary. Shape differences must be stated, but exact physical equivalence is not a prerequisite for a performance control. Custom-solver correctness remains required.

The plasma control is an exact torus specialization, R100/r20 cm inside the same Fe56 shell; it is not nonaxisymmetric WISTELL plasma. The coil has a radius-5 cm circular tube around an R100 cm near-circular cubic axis. Its native torus has the same nominal round section and an exact circle. The built-in ring uses radial radii95/105 cm and z=±5π/4 cm, matching round-torus volume but a different rectangular section.

The observed ratio of wall medians is about1.0084 for plasma,1.3712 for coil versus torus, and1.4302 for coil versus ring. These are three-seed descriptive observations, not confidence-qualified portable performance. The coil transport medians differ by approximately735× versus torus, while startup/output dominate this200-history wall result. This is why low-history full wall can appear reasonably close despite a poor transport kernel. Do not extrapolate exact large-run costs without measuring scaling and tally/output policy.

## Comparisons still required for the main goal

1. **Actual nonaxisymmetric plasma** versus a similarly sized built-in torus with the same source, physics and tally/output contract. Current real-WISTELL comparison is against DAGMC and lacks total wall.
2. **Real curved coils / a period or full collection** versus built-in circular or ring approximations at comparable count, placement, gross size and section scale. The saved48coil2.46s wall study is against DAGMC, not an equivalent builtin-CSG collection.
3. Same complete native geometry-service test for old local/BVH, repaired/certified and native controls, with distance/classification/normal/inside exits/misses and complete failure reporting. The0.01761% result is this separate primitive workload, not a200-history wall-time percentage.
4. Small and production-relevant workload sizes after admitted bounded pilots, separating setup from scaling, tally-off/on and output overhead. Geometry build/export time must be recorded if the target metric begins at source geometry inputs.

Use approximate built-in geometry openly as a cost target. Report its fidelity differences separately; do not require its tallies to equal the custom shape's physics. Local scoring correctness of each method and regression between same-solid implementation variants remain separate obligations.
