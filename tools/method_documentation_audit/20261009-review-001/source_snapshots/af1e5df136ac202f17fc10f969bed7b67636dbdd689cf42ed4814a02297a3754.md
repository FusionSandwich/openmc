# StellarCSG methods and failures ledger

Prepared October 8, 2026 from retained local records through October 1. Source IDs resolve in [EVIDENCE_INDEX.md](EVIDENCE_INDEX.md). Read [START_HERE.md](START_HERE.md) for the target, latest checkpoint and measured timing table.

“Partial” means useful under the stated scope; “failed” means a concrete attempted gate failed; “unresolved” means the evidence cannot settle it; “not run” means no relevant execution is established. A method can have more than one status. This ledger covers the documented method families and supporting infrastructure found in the project; it is not a claim that every disappeared cloud workspace or every local log has been reconstructed.

## Comparisons and claims to reject

| Tempting claim | Why the record does not support it |
| --- | --- |
| “The 48-coil result solves physical winding-pack transport.” | It models thin round tubes in near-vacuum with no tallies. |
| “0.23-second old runs prove generic BVH speed.” | Reconstructed constructor checks predict approximate-circle analytic torus dispatch. |
| “7.836 versus 8.652 seconds passed the pack goal.” | PCA envelopes used sections roughly 64–260 cm by 13–408 cm and different source occupancy. Corrected rings failed. |
| “The AABB edit alone improved transport by 37–41%.” | Old/new compiler strict-FP/runtime provenance differs; same-build stochastic transport was not run. |
| “The solver regressed from 0.36 seconds to 35 seconds.” | History count, material collisions, sources, tallies and runtime differ. Matched old/current replay was only 1.064083 times. |
| “Fourfold Bernstein speedup meets the native target.” | Internal summed distance and child-wall denominators are different from native transport. |
| “67% of transport is minimum search.” | 67.19% was exclusive offset geometry-service time in one diagnostic. |
| “0.01761% is the final native transport ratio.” | It belongs to a standalone complete primitive workload. |
| “Equal raw tallies prove correct geometry.” | Both native variants reproduce deterministic shared owner/continuation failures. |
| “No lost particles means no missed boundary.” | Silent skips and wrong per-bin ownership can preserve exits and totals. |
| “All 160 scalar queries pass, so normals and imported coils pass.” | Nine normal gaps and imported miss-only records remain. |
| “Dyadic tests prove native repair works.” | Pure arithmetic passed; native configure timed out before compilation or rows. |
| “Embree lost to CSG in the full-set benchmark.” | The timed full-set binary was ordinary DAGMC, not Double Down. |
| “An unavailable or unsubmitted route failed mathematically.” | NOT_RUN, unrecovered and unsent are distinct from attempted numerical failure. Two prepared briefs were never sent. |
| “All saved reports describe active work now.” | Historical running snapshots are superseded by terminal receipts. This packet does not freshly inspect processes. |

## Recommended review order

Start with M23 and the native assembly counterexamples to decide the supported correctness domain. Then assess M14/M15 against the repaired domain and M04 with complete-query workload attribution. Keep M02/M05 as preserved analytic/general-tube evidence, and M11 as a restricted correctness reference. Review M16/M17 as alternative mechanisms only after identifying the exact artifacts and physical target they can support. Avoid another broad timing campaign until the reviewer has identified a concrete falsifiable change and its independent acceptance conditions.
