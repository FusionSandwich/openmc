# P00 native event repair design — review proposal, October 1, 2026

## Decision and scope

Recommend an **experimental, certified planar-event path**, introduced in two
small stages: first axis-aligned plane controls, then supported transverse
facet contacts. Carry certified one-sided region state through a boundary
crossing; preserve a distinct positive interval even when it contains no
binary64 interior point. Do not begin with a global coincidence-tolerance
change or a combined-component conflict guard.

This is a design proposal, not an implemented or validated repair. This turn
read local source and retained evidence and writes only this new memo. No
production edit, build, native client, transport, dependency acquisition or
successor launch is authorized or performed. The prior root execution stop is
preserved. Every future build/run requires its own root-reviewed frozen plan,
fresh resource admission and shared compute lease.

## Context: what the evidence establishes

1. [The 680-row assembly audit](P00_ASSEMBLY_REPORT_20261001.md) used 18 native
   component-selector facet surfaces. Baseline/current rows, scores and
   exceptions match exactly. Its failures therefore predate the tested AABB
   shortcut. This finite equivalence is not a universal equivalence proof.
2. [The focused plane result](P00_ASSEMBLY_PLANES_FOCUSED_RESULT_20261001.md)
   independently demonstrates a current-library successor error without the
   facet adapter. Reverse gap48 correctly selects B's exit at .75, yet finds
   A instead of background. A receives the following gap-inclusive pathlength.
   Baseline timed out with zero rows; token-reversal clients were not run.
   There is no paired-plane result.
3. For that recorded event position, A's plane residual is the exact nonzero
   `2^-48`. `Surface::sense` replaces its sign with directional sense because
   it is below FP_COINCIDENT. The selected B token overrides B only; A still
   calls that generic sense. The source trace explains this observed row.
4. The facet reverse gap48 row also demonstrates a different error:
   individual distances .75 and .7500000000000036 are distinct, but the
   Region reducer can retain the later contact under FP_PRECISION.
5. Touching facets can have a correct first owner/score followed by an abort
   on the other surface's unhinted origin contact. The reverse ray's original
   token order works; equivalent reversed tokens can fail on continuation.
   Selected representative ID alone is not a sufficient failure criterion.
6. Actual-derived intersection-ray certificates contain distinct positive
   intervals approximately 6.398e-16–1.465e-14 cm wide, not exact ties.
   Correct first surface selection alone did not ensure correct ownership.

## Required contract

The repair acts on the represented input geometry and authoritative ray bits.
It must establish the following before accepting the affected event:

* **Order:** identify the earliest relevant positive contact. Close values are
  not equal events. Equal returned doubles or overlapping error intervals do
  not certify equality; use a predicate that returns BEFORE, EQUAL, AFTER or
  UNKNOWN. UNKNOWN remains unsupported unless a reviewed fallback resolves it.
* **Membership:** classify the open interval immediately after that event.
  Only certified contacting surfaces receive an outgoing-side override;
  noncontacting near surfaces retain their certified strict side.
* **Progress:** remove an already consumed origin contact by identity and exact
  parameter, not by an absolute distance band. A later hit on the same surface
  is not consumed by the old hint.
* **Accounting:** transport and score every required positive interval in its
  own cell. A true tie has zero intervening length and one atomic owner change.
  Small global score error does not excuse lost cell bins or surface events.

These are proposed acceptance conditions. Ordinary code tolerances alone are
not certificates of represented topology or an error bound for these conditions.

## Proposed minimal event context

Keep the public ordinary Surface/Region interfaces initially intact. Add an
experimental internal context to BoundaryInfo/GeometryState and explicit
context-aware Region/CSG lookup overloads. It must not be inferred from the
legacy single `surface()` marker.

| Field | Meaning and invariant |
|---|---|
| Ray epoch, anchor P0 and direction D0 | Defines P(s)=P0+s D0; use the same bits in all surface queries. Initial scope is unit axis rays. |
| Certified parameter/current contact key | Exact or rigorously certified represented-ray event; a rounded double alone is insufficient. |
| Contact group | Deduplicated signed native surface tokens, local contact identity/normal witness and coordinate level, all certified at the same parameter. |
| Outgoing side overrides | Sides immediately after the entire group; never overrides a surface merely because its rounded residual is small. |
| Strict nearby noncontact sides | Certified sides evaluated at the anchored event point; bypass ordinary proximity-based directional sense for those tokens. |
| Consumed contact keys | Keys already handled in this ray epoch; their zero contacts can be skipped without suppressing positive future contacts. |
| Next separating parameter, where certified | Bounds the open interval, gives its positive length and certifies override validity. |
| Status and reason | CERTIFIED, UNKNOWN_ORDER, UNKNOWN_SIDE, UNSUPPORTED_CONTACT, UNSUPPORTED_TRANSFORM or UNREPRESENTABLE_LENGTH. |

A context is invalidated by a direction change, source restart, boundary
condition transformation, collision or coordinate-frame change. Rebuild it
with certified state before claiming continued support. Merely clearing it and
falling back to legacy sense during an unresolved cluster is not a valid repair.
Restart files/secondary banks presently retain one surface ID, so context
serialization is an explicit later integration gate.

This is a small transient boundary context, not a proposed global cache of
all selector sides. Candidate sets must still be complete: for successor
certification, include every region token that could change the candidate-cell
decision. A neighbor list or spatial partition is an accelerator, not proof
that an unsearched cell/token is irrelevant. Fall back to a context-aware full
search within the supported universe when completeness is not certified.

## Stage 1: repair the demonstrated built-in axis-plane subset

Scope the first implementation to finite axis-aligned planes, one universe and
coordinate level, unit axis rays, transverse contacts, explicit Boolean priority
cells, and void deterministic events. Other geometry remains on the existing
path except when it participates in the unresolved cluster: then this
experimental path reports unsupported. Do not advertise general native CSG or
P00 acceptance from this stage.

An unchanged enclosing primitive is permitted in a control only if a
conservative boundary-distance bound proves it cannot participate in the
cluster; otherwise it is unsupported. Use an outer axis-plane box for the
fully supported Stage 1 fixture. Retain the original sphere-enclosed plane
counterexample separately and compare its local events under a certified
separation bound rather than claiming the sphere itself was repaired.

Within that subset, plane position order and signs are comparisons of the
stored dyadic coordinates. For a common axis/unit direction, contact ordering
can be certified directly from plane offsets; this avoids introducing a general
exact-arithmetic dependency as the first patch. Represent parameter/difference
keys without losing exact subtraction information. Any broader arithmetic
backend needs a separate implementation/proof review; long double alone is not
a prescribed exact fallback.

Suggested reviewable patch sequence:

1. Add context/types and pure plane event-order/strict-side operations behind
   the existing experimental feature boundary. Add predicate controls, without
   switching navigation. Specify behavior for overflow, underflow, signed zero
   and unknown comparisons. Inventory local capabilities before any future build.
2. Wire plane Region queries, complex virtual traversal, cell lookup and
   particle continuation to that context as one **opt-in functional unit**.
   A correct-minimum-only or correct-sense-only patch can be independently
   reviewed, but cannot pass the end-to-end gate or be enabled as the full fix.

Detailed behavior for the recorded reverse gap48:

* Certify B exit at s0=.75 before A entry s1=.75+2^-48.
* At B exit, certify B outside and A strictly outside at P(s0); choose
  background. The A residual is nonzero and cannot take directional sense.
* Query from that anchored event state. B's consumed origin is suppressed;
  A's positive next parameter is preserved even though below FP_COINCIDENT.
* Compute delta = round_to_binary64(exact(s1-s0)), **not**
  round(s1)-round(s0). Score delta=2^-48 in background; then enter A.
* Require background flux 2^-48, B flux .75 and the subsequent A interval
  without the gap. Require B exit current followed by A entry current, with
  native plane-normal signs (+x for each x-plane: reverse B exit current -1,
  reverse A entry current -1). Facet outward-normal signs differ and are checked
  against each contact's own normal rather than copied from the plane fixture.

Complex Region traversal uses an anchored parameter and one-sided Boolean
state for masked virtual contacts. It must not discard a positive contact
because the previous virtual crossing was near it. Purely masked contacts may
advance the internal search without changing owner or emitting a native cell
boundary score; their state updates still constrain subsequent events.

The TINY_BIT recovery nudge is forbidden as a success path inside a certified
cluster unless a certificate proves it crosses no required intervening event.
No such proof means an explicit terminal limitation, with its reason retained.

## Stage 2: supported facet and true-tie integration

After separate Stage 1 review, extend the same context to per-selector facets;
do not replace native P00 by a combined-component kernel.

Facet candidate data must carry the represented supporting plane, certified
triangle-domain inclusion and origin-contact identity. A nearest-hit double
plus normal_at is insufficient. Use error-bounded fast predicates with a
reviewed exact/adaptive fallback for inconclusive order, plane-side and edge
tests. Retained Fraction code remains an independent acceptance oracle, not a
production dependency. The fallback's arithmetic, domain limits, compiler
contract and worst-case budget must be chosen and reviewed before this stage
is implementation-ready. No assumption of a presently available exact library
or acquisition is made here.

For a resolved transverse face contact, recognize exact t=0 versus exact t>0;
do not discard a positive re-entry on the same selector under an abs(t) band.
Coplanar triangle seams representing one local oriented plane can share one
contact. Creases, vertices, coplanar ray intervals and unproved local domains
remain explicitly unsupported until their one-sided geometry is defined and
certified. A generic normal existence test cannot promote them to support.

For a certified true tie, collect all necessary selector contacts and apply
all outgoing sides atomically before choosing the successor priority cell.
Touching A/B with opposite outward normals is a valid B→A or A→B event; opposing
normals across different components do not themselves require abort. Identical
solids retain their explicit priority owner. Deduplicate same-selector coplanar
facets before recording a contact, and consume every group origin key so the
next query does not encounter an unhinted duplicate at zero.

Use stable native user surface IDs to choose a canonical representative for
the legacy single-surface field, independent of XML/token/facet iteration order.
The group drives navigation; the representative does not. Relabeling IDs is a
separate semantic transformation; compare mapped geometry/owner contracts and
document representative score remapping rather than asserting ID invariance.

**Scoring decision for the smallest staged path:** retain the existing
one-representative-surface estimator contract, but make its representative
deterministic and explicit in diagnostics. Record the full contact group as
well. Each atomic owner transition updates cell_last/current exactly once;
no artificial zero-length intermediate cells or duplicate aggregate currents.
The chosen representative contributes its own normal/sign, not an arbitrary
normal averaged across opposite contacts. Acceptance checks the documented
canonical bins, not equality to a historically token-dependent choice.

This deliberately does **not** promise a crossing score on every coincident
physical/component surface. A tally configuration requiring that interpretation
must remain unsupported by the staged path or wait for a separately reviewed
multi-contact SurfaceFilter/tally contract. Do not silently call canonical-only
current complete per-component scoring. An all-contact extension would require
per-contact normals and filter matching, explicit treatment of duplicate
definitions, and single-count cell-to-cell/aggregate semantics; calling the
present score_surface_tally twice can double count aggregate/partial currents.
That extension is a release gate whenever those scores are requested.

## Intervals with no representable interior position

Separate three cases; the gap48 example has many interior binary64 x values
and is not itself the hardest representability case.

1. **Adjacent binary64 boundaries, no binary64 interior point.** For example,
   A ends at x=1 and B begins at nextafter(1,+inf)=1+2^-52. The reverse interval
   has positive length 2^-52. The outgoing cell can be background at B's
   boundary with certified one-sided state, even though r has no strictly
   interior representable x value. Traverse and score that interval, then
   process A. Lack of an interior point alone is not a reason to abort or merge.
2. **Distinct rational contacts whose rounded positions or absolute parameters
   coincide.** Keep the anchored ray, certified parameter order and one-sided
   owner separate from rounded Cartesian storage. Form the local delta from
   the exact parameter difference. A rounded position may remain unchanged
   while logical progress and scored length are positive. Re-querying facets
   solely from the rounded r would lose the original represented ray and is
   prohibited in this mode. Bound the number of contacts processed; progress
   means a strictly later certified key, not a changed floating coordinate.
3. **Positive delta cannot be represented by the enabled advancement/scoring
   arithmetic, or state-dependent evaluation is unsupported.** The minimal
   implementation terminates with UNREPRESENTABLE_LENGTH or a named evaluator
   limitation. It must not set delta=0, merge the contacts, nudge across the
   interval or score it to an adjacent owner. Wider arithmetic/compensated
   accumulation or a quantified scientific error contract is a later design,
   not implicit permission to discard the interval.

Stage 1 and the first facet stage support deterministic void segments only.
For material-filled unresolved-coordinate segments, merely adding flux lengths
after jumping to the far boundary is invalid: collision sampling, reaction
scores, material/temperature changes, time cutoffs, timed/mesh/spatial filters
and secondaries can depend on intermediate state. Either provide certified
logical state to every required evaluator or reject that configuration before
pretending to support full transport. Direction-changing collisions also
require rebuilding the ray epoch. A seeded collision deliberately inside a
thin material interval is an eventual mandatory integration test.

An unsupported event invalidates acceptance of that history/run. Keep valid
earlier segment scores as diagnostics, clearly marked partial; no fabricated
score for the unresolved interval and no success statepoint. Plan/successor
selection should be certified before committing the affected event's scores
where possible. Do not require erasing legitimate already-completed segments,
or treat their presence after a later abort as evidence of a fabricated score.

Oracle acceptance must not use the same native tolerance to derive expected
owners. Exact analytic slabs and supporting-plane/parity certificates remain
separate constructions. Check output cardinality and lengths, finite scores,
explicit terminal status and every local bin. Mutation controls must reject
collapsed gap, swapped contact, incorrectly merged rounded-equal parameters,
wrong owner, shifted interval into a neighbor bin, missing group origin key,
duplicate current and an abort falsely promoted to PASS. For exact dyadic
controls demand exactly representable expected lengths; for general rational
deltas bind the rounding/accumulation rule and audit the local error, rather
than using a blanket 2e-9 tolerance that hides an omitted sliver.

Stage 1 passes only after both fully completed matched-build plane controls
and independent Sol review. The prior baseline plane timeout must be completed
or explicitly remain an incomplete comparison, never relabeled a pass. Stage 2
requires native assembly outcomes plus exact oracle controls; a standalone
driver or unchanged global tallies cannot close it. Stop each separately
admitted execution phase on an unexplained difference or abort; no automatic
successor launches.

## Alternatives and release boundary

Reject a global FP_COINCIDENT reduction, an unconditional strict-double minimum
presented as a complete fix, a global epsilon/nextafter nudge, and equality
grouping by rounded distance. Each leaves at least one demonstrated mechanism
or representability problem unresolved. A safety-only detection/terminal guard
is a possible preliminary stage, but must be labeled coverage loss, not a
functional navigation repair. It must detect uncertainty, not blanket-reject
all valid multi-component contacts.

Mesh regularization is an alternative **new scientific input**, not a hidden
navigation repair: it would require explicit authorization, fresh payload IDs,
topology/overlap/displacement and interval-ownership certificates, score mapping,
and new native comparison. A mesh minimum edge/feature size alone cannot prove
all ray contact separations: rays arbitrarily near an intersection or tangent
can have arbitrarily short intervals. A minimum-interval gate can qualify a
specified ray/input family under a documented separation/error bound; it cannot
silently qualify arbitrary rays from a component AABB or edge-length bound.

Even a validated staged repair would support only its declared represented
geometry/ray/evaluator contract. Continuous CAD fidelity, periodic physical-coil
ownership, per-physical-coil scoring and the performance target remain distinct
publication gates. This memo grants no publication acceptance or production
matrix admission.
